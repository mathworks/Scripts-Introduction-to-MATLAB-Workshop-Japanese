# MATLAB<sup>&reg;</sup> 入門ハンズオン用スクリプト

MATLAB 体験会で使用するスクリプト集です。

## 体験会概要
MATLABをこれから使おうとされている方や久しぶりに使用される方を対象として、MATLABを使い始めるための入門的な操作方法や情報をご紹介します。

MATLABの概要説明や画面の操作方法、MATLAB言語の基本的な内容から始まり、データのインポート、可視化、カスタムの解析アプリ作成まで講師と一緒に作業しながら、MATLABの使いやすさや活用方法を実感できる内容となっています。

表計算ソフトウェアを使って1ファイルずつおこなっている処理を複数ファイルでまとめて処理したい、MATLABを自己流で使い始めたので操作方法を学習したい、普段はSimulink<sup>&reg;</sup> の操作がメインだがデータ解析や可視化など幅広く活用したい、などの課題がある方はぜひご参加ください。

## ハイライト
- MATLAB 概要
- デスクトップの基礎
- データの可視化
- 手軽に GUI アプリ作成
- MATLAB Copilot の活用
- 学習リソースの紹介
