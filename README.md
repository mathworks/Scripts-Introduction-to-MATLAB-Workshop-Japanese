# MATLAB<sup>&reg;</sup> 入門ハンズオン用スクリプト

MATLAB 体験会で使用するスクリプト集です。
[![Open in MATLAB Online](https://www.mathworks.com/images/responsive/global/open-in-matlab-online.svg)](https://matlab.mathworks.com/open/github/v1?repo=mathworks/Scripts-Introduction-to-MATLAB-Workshop-Japanese)

## 体験会概要
MATLAB をこれから使おうとされている方や、久しぶりに利用される方を対象として、MATLAB を使い始めるための基本的な操作方法をご紹介します。
MATLABの概要説明や画面操作、MATLAB 言語の基礎から始まり、データの読み込み、解析、そして生成AI「MATLAB Copilot」を活用したコーディング、そしてデータの特徴をわかりやすく伝えるための可視化テクニックを体験いただけます。
 
表計算ソフトで行っている集計やグラフ作成を効率化したい方、MATLAB を自己流で使い始めたので操作方法を学習したい方、
普段はSimulink の操作がメインだがデータ解析や可視化など幅広く活用したい方、
データ分析や可視化の基礎を学びたい方におすすめの内容です。


## ハイライト
- MATLAB概要、使い方
- データの読み込み、解析
- 魅せるための可視化テクニック
- MATLAB Copilot の活用
